HOW THE ENQUIRY FORM WORKS
The popup asks for name, mobile number and preferred plot size. On submit, it opens WhatsApp with a pre-filled enquiry message addressed to +91 88513 86063. The visitor must press Send in WhatsApp. This static website does not store leads in a database or silently send messages. For automatic lead storage, connect a backend/CRM or Meta Pixel/Conversions API separately.

HOSTING
Upload the complete folder contents to the document root of your hosting account (for example public_html). Keep the assets folder alongside index.html. Do not upload only index.html.

SEO BEFORE PUBLISHING
1. The canonical URL, Open Graph URL, robots.txt and sitemap.xml currently use https://gangarivera.com/. If you publish on another domain or subdomain, replace that URL in index.html, robots.txt and sitemap.xml.
2. Add the final domain to Google Search Console and submit /sitemap.xml.
3. Add a verified Google Analytics / Meta Pixel only if you need tracking and have an appropriate consent/privacy setup.
4. The site uses Google Fonts; it still works with fallback fonts if Google Fonts are unavailable.
